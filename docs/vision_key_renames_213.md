# Vision key renames (CHANGES 213, 2026-11-27)

Every vision key now names the machine first and, where the value belongs to one model, the model next:
`vision.<vendor>.<check>...` or `vision.<vendor>.<dost|dostplus>.<check>...` (`utils/VisionKeyNames.py`).

All 461 keys per machine moved from `<vendor>.vision.<rest>` to `vision.<vendor>.<rest>`; the 120 below also moved
their model forward (or gained it: the silver cap = DOST, the brass cap = DOSTPLUS, and keys read only by one model's
method). Shown without the vendor; in the properties file put `siemens` / `allenbradley` after `vision.`.
